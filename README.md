# NBA Fantasy 王朝 · 二十季重建聯盟 (Dynasty GM)

> 致敬並擴展自 [fudoubleg.com](https://fudoubleg.com/) 的純瀏覽器免註冊 NBA 球隊總經理（GM）經營模擬遊戲。

玩家將帶領一支自訂擴張球隊加盟現代 NBA 30 支勁旅，在嚴格的聯盟薪資上限（Salary Cap）體系下運籌帷幄。經歷擴張選秀、球員交易、自由市場補強、新秀選拔與像素即時戰術季後賽，展開長達二十個球季的史詩王朝競逐！

---

## 🌟 核心特色 (Core Features)

1. **擴張自訂隊 (Expansion Franchise)**
   - 挑選台北黑熊（Taipei Bears）、西雅圖超音速（Seattle Supersonics）、拉斯維加斯暴徒（Las Vegas Outlaws）等加盟城市，或完全自訂隊名與球隊主色。
   - 成為全聯盟第 31 支球隊，加入東區或西區聯盟。

2. **開局擴張選秀與 30 隊真實球星庫 (Draft Pool & 30 NBA Teams)**
   - 內建 30 支現代 NBA 球隊（波士頓塞爾提克、洛杉磯湖人、金州勇士、丹佛金塊、達拉斯獨行俠等）真實陣容與各隊代表色。
   - 涵蓋 Jokic、Doncic、Giannis、Curry、LeBron、Wembanyama 等巨星與數百位輪替球員。
   - 開局於 $140M 薪資上限內挑選 8 位擴張建隊基石。

3. **深度經營管理 (Front Office & Roster Management)**
   - **薪資上限與奢侈稅**：管理 $140M 工資帽與 $170M 奢侈稅警戒線。
   - **輪替調度**：調整先發五虎順位、掌控傷病名單、裁撤球員。
   - **跨隊交易中心 (Trade Center)**：挑選聯盟其他球隊提出交易報價，系統依據薪資對等性與球員評分/年齡價值即時審核。

4. **像素 2D 籃球場現場模擬 (Pixel Court Game Simulation)**
   - 復古木紋像素籃球場，以即時 Canvas 渲染球員走位、擋拆、後撤步跳投、拋投與禁區暴扣！
   - 即時中文文字戰況轉播牆，支援 1x / 2x / 5x 速度與一鍵跳至終場。
   - 現場教練臨場指令：隨時切換「魔球三分」、「衝擊禁區」、「全場壓迫」戰術！

5. **休賽季王朝進程 (Offseason & 20-Season Dynasty)**
   - **球員夏訓與生理年齡報告 (Progression & Regression)**：年輕新秀依潛力大幅增長 OVR，顛峰期維持，老將運動能力漸次退化。
   - **年度新秀選秀大會 (Rookie Draft)**：每年產生全新潛力新秀池，考驗選秀眼光。
   - **自由球員市場 (Free Agency)**：利用剩餘薪資空間簽下關鍵自由球員。
   - **二十季史詩終章結算 (Dynasty Finale)**：累積冠軍金盃、生涯勝率、榮譽勳章，評定王朝歷史地位！

6. **本地永續儲存與存檔匯出 (Local Persistence & Save/Load)**
   - 無須註冊，遊戲進度與榮譽勳章永久保存在瀏覽器 `localStorage`。
   - 支援一鍵匯出/匯入存檔代碼，換電腦也能無縫接軌。

## 🚀 本地開發與啟動 (Getting Started)

### 需求
- Node.js (v18+)
- npm

### 安裝與執行
```bash
# 安裝依賴
npm install

# 啟動開發伺服器
npm run dev

# 構建生產版本
npm run build

# 預覽構建結果
npm run preview
```

啟動後於瀏覽器造訪 `http://localhost:3000` 即可暢玩！
